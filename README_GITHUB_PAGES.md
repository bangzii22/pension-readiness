# Pension Readiness Calculator - GitHub Pages

This is a static HTML/CSS/JavaScript pension calculator.

## Upload to GitHub

1. Create a new GitHub repository, for example: `pension-readiness-web`.
2. Upload these project files to the repository root:
   - `index.html`
   - `styles.css`
   - `src/pension.js`
   - optional: `package.json`, `package-lock.json`, `tests/`, `README_GITHUB_PAGES.md`
3. Commit the files to the `main` branch.

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Under “Build and deployment”, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Click Save.
5. Wait 1–3 minutes.

Your public URL will usually be:

`https://YOUR-GITHUB-USERNAME.github.io/pension-readiness-web/`

## Wix embed

In Wix Editor:

1. Add Elements → Embed Code → Embed a Site.
2. Paste your GitHub Pages URL.
3. Resize the embed frame height to about 1400 px.
4. Publish Wix.
